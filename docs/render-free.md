# Бесплатная публикация на Render

Для этой публикации не нужен Ubuntu-сервер, SSH, Nginx или банковская карта. Render
собирает корневой `Dockerfile.render`: React и FastAPI работают по одному HTTPS-адресу,
а PostgreSQL создаётся из `render.yaml`.

## Публикация

1. Войти на [Render](https://dashboard.render.com/) через GitHub.
2. Нажать **New → Blueprint**.
3. Выбрать репозиторий `arlequin-stack/Zhuanyshev-Rustem-25-IST-1-BookNest`.
4. Render найдёт `render.yaml`. Нажать **Deploy Blueprint**.
5. Дождаться статуса **Live** у `booknest-library`.
6. Открыть `https://booknest-library.onrender.com`.

При первом запуске автоматически выполняются миграции и добавляются демонстрационные
книги. Swagger UI доступен по адресу `/api/docs`, проверка сервиса — `/health`.

## Проверка

- открыть каталог и карточку книги;
- зарегистрировать читателя и войти;
- войти как библиотекарь: `librarian@example.com` / `Library123`;
- проверить панель библиотекаря и создание книги;
- открыть `/api/docs` и `/health`.

Бесплатный веб-сервис засыпает после периода без запросов, поэтому первое открытие может
занять около минуты. Бесплатная PostgreSQL-база Render действует 30 дней. Перед окончанием
срока для сохранения данных нужно сделать экспорт или создать новую бесплатную базу.
