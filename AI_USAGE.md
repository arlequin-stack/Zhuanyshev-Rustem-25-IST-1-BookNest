# AI usage declaration

AI-ассистент использовался для первичного каркаса BookNest, проверки требований силлабуса,
типизации и подготовки тестов. Архитектурные решения, бизнес-правило выдачи книги,
валидация, миграции и весь код должны быть разобраны студентом до защиты. Студент обязан
уметь объяснить любую строку и самостоятельно внести изменение по запросу преподавателя.
